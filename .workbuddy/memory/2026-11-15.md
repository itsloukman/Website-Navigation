# 2026-11-15

## Craft 开源创作软件专区接入 AI365 导航

- 需求：把 https://www.scys.ai/insights/craft-apps-chinese-directory/ 的 20 款软件拆解加入导航站。
- 真正的数据源是 https://www.scys.ai/craft-apps/ 页面内嵌的 `const CATS` / `const APPS` JSON（8 类 / 20 款 / 73 个官方下载直链），文章页只是介绍。以后抓这类页面优先看内嵌 JS 数据，别只解析渲染后的正文。
- 方案：新增顶层分类 `craft_apps`（section `craft-apps-section`、grid `craft-apps-grid`、子分类统一 `craft_` 前缀），不混入既有 AI 分类；sites-data.js / sites-data-en.js 各加约 439 行双语条目，保留中文说明、英文说明、版本号、平台直链、文档、安装说明、来源链接。
- 卡片扩展：`createSiteCard` 支持可选 `downloads / docs / install / visitLabel`，带下载数据的条目自动加 `.craft-card` class 和下载 chips；`language.js` 里覆盖 `.visit-btn` 文案的逻辑改为尊重 `data-visit-label(-en)`，避免自定义「查看发布页 / View Releases」被改回「访问 / Visit」。
- 顺手修好既有 bug：`sites-data-en.js` 的 Deco 条目缺 `tags`（还带一条错误重复的 `url: https://pir.org/`），导致 `loadSites()` 在 ai_coding 处抛 `Cannot read properties of undefined (reading 'includes')`，后面的 ai_prompts / ai_search / 新分类全部不渲染。已补 tags、清掉脏 url，并把两处卡片函数的 `site.tags` 改为容错的 `siteTags`。修完后全站可见卡片从 557 增至 648。
- 交互约定：首页沿用「8 张 + 显示更多」折叠；从侧边栏进入或点击子分类时 `filterCraftAppsSubcategory(key, true)` 展开全部 20 款。搜索索引、SEO 分类组、hash 滚动映射、底部快速导航、中英字典均已接入。
- 验证：Node vm 渲染测试 + Chrome headless / CDP 真实页面测试。中英页各 20 张卡片、71 个 `releases/download` 直链 + 2 个社区 `releases/latest` + 40 个文档链接；子分类筛选（图形与设计 7 款、社区 2 款）、站内搜索命中、语言切换均通过；抽查 3 个直链 HTTP 200。
- 生效文件：`index.html` / `en.html` / `js/sites-data.js` / `js/sites-data-en.js` / `js/scripts.js` / `js/language.js` / `css/styles.css` / `README.md`。`index_fixed.html`、`index_backup.html`、`scripts_new.js` 等是历史备份，未改。
